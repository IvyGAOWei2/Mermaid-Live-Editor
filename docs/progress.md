## 已知使用限制

- 草稿只在当前浏览器和域名，不跨设备同步；通过 `.mmd` 转移。只留一份覆盖备份。
- Mermaid 自动布局，不支持单节点自由拖拽。大图性能受设备限制。
- 源码 100,000 字符、流程图 600 条连线；配置指令、YAML 头部、远程图片、链接和 HTML 不在支持范围。
- 系统 Node 18 不能直接运行当前工具链；本工作区用 PowerShell 脚本，新电脑先安装 Node 22。
