# v0.1 需求

状态：v0.1 功能已实现并部署，本地检查、GitHub CI 与关键线上验收通过；用户体验验收和 PR 状态见 [progress.md](progress.md)，验证覆盖见 [verification.md](verification.md)。

## 背景与目标

将外部 AI 生成的 Mermaid 粘贴到一个中文个人网站，像修改 Markdown 一样修改文字、连接和结构，同时查看图形与语法说明，减少工具切换。使用 Mermaid 开源库渲染，不复刻官网或自行实现绘图引擎。

参考：[Mermaid 文档](https://mermaid.js.org/)、[Mermaid Live Editor](https://mermaid.live/)。

## 使用流程

1. 外部 AI 生成 Mermaid → 粘贴代码 → 修改文字和结构 → 实时预览 → 本地保存 / 导出。
2. 输入缩进大纲 → 转换为 Mermaid 思维导图 → 修改代码 → 预览与导出。

第一版仅承诺支持 `flowchart` 和 `mindmap`；分别提供模板，不将任意流程图自动转换为思维导图。

## 必须完成

- 中文界面；电脑端左右分栏，小屏可用。
- 左侧代码高亮编辑器，支持常规撤销 / 重做；右侧实时预览。
- 流程图、思维导图模板；独立的大纲转换入口。
- 可按需展开的中文语法帮助，含解释和可插入示例。
- 帮助覆盖节点文字、连线条件、判断分支、方向、分组、思维导图缩进。
- 明确语法错误；错误时保留最近成功图形，修复后继续预览。
- 缩放、平移、适应窗口；Mermaid 自动布局，不支持自由拖动单独节点。
- 浏览器本地自动保存和刷新恢复，清晰显示保存中 / 已保存 / 保存失败。
- 导入 / 导出 UTF-8 `.mmd`；导出中文完整的 SVG。
- 切换模板、导入、应用大纲等覆盖操作防止意外丢失草稿。
- 页面及手册说明：不同电脑可访问同一网站，但草稿只在当前浏览器，不跨设备同步；通过文件转移。
- 浏览器内处理；用户输入不默认上传 GitHub、日志或第三方服务。

## 不在 v0.1 范围

AI API、账号、数据库、跨设备同步、多人协作、自由拖拽节点并固定位置、复杂可视化结构编辑器。不承诺支持所有 Mermaid 图类型或超大图表。

## User Stories 与验收

### 1. 编辑流程图

作为经常画流程图的用户，希望修改代码中的文字和连接关系以减少切换。粘贴有效代码后显示图形，修改中文文字、条件和连线后正确更新。

### 2. 边编辑边学习

作为初学者，希望查阅中文语法。能够找到节点、判断、分支、方向等常用写法，直接插入示例并继续编辑。

### 3. 从大纲生成思维导图

作为整理思路的用户，希望保留缩进层级和中文。合法大纲转换后可继续编辑；混用或不明确的缩进、多个根节点、跳级等情况给出可操作说明，不能悄悄猜测层级。

### 4. 保住微调工作

作为反复调整的用户，希望错误与刷新不轻易丢失工作。错误不导致页面崩溃，保留最近成功图形；最近保存代码刷新后恢复；修复错误后恢复正常预览。连续快速编辑时，以最新输入为准。

### 5. 保存成果

作为需要保存图表的用户，希望保留可编辑源码与图片。导出的 `.mmd` 能重新导入，中文不变；SVG 可正常独立打开；当预览为旧图时明确告知并避免误导导出。

## 分阶段开发清单

1. 检查环境 / Git / 项目指令；写入需求与方案。
2. 打通编辑、渲染、本地保存与导出，处理错误和异步更新。
3. 加入模板、语法帮助、大纲转换与覆盖保护。
4. 完成关键测试、浏览器检查、生产构建。
5. 准备 GitHub CI、提交与 Vercel 配置；具备连接条件后推送、PR、预览、发布。
6. 用实际验证结果更新手册、进度、版本记录。

前四阶段、本地部署准备与开发分支推送已完成，Vercel 已自动连接并上线。PR 与线上验收按进度文件记录，未执行的合并或完整设备验收不算已完成。
